# 储研 Chuyan｜储能项目投资测算展示版

[English README](README.en.md) · [在线体验](https://wangweiyi-wwyz.github.io/Chuyan-demo/)

储研是一款面向储能项目初步投资分析的浏览器工具。你可以调整项目、收入、成本和融资假设，比较不同情景下的项目回报与现金流，并查看测算结果如何反映到财务报表中。

## 主要功能

### 项目工作台

- 工作台集中显示当前项目的额定功率、储能容量、建设投资和融资比例。通过配置进度进入各参数页，并在首页切换全投资和项目资本金口径，预览三情景 IRR。

### 项目与时间轴

填写项目名称、所在城市、项目阶段、建设开始日、建设期和运营期。示例采用山西独立储能电站、半年建设期和 20 年运营期。页面自动推导商业运营日和运营结束日，并可分别设置全投资与资本金折现率，记录参数来源及备注。

### 技术与运行

配置磷酸铁锂电站的额定功率和容量、SOC 运行范围、充放电效率、运行计划及容量衰减。实时预览初始可用容量、往返效率和首年交流侧放电量，为后续收益测算提供电量基础。

### 投资与运营成本

- 按含税或不含税口径录入建设投资，逐项设置进项税率、抵扣比例、折旧年限和残值率，查看资产入账基数。
- 配置首年固定运营费用及年增长率，按运营年安排补容或电池更换，记录退役与新装容量、停机和旧设备回收。通过费用图表和年度明细核对运营支出、更新投资和税额。

### 收益配置

- **现货交易**。配置购电价、售电价、价格增幅和交易费，结合运行假设估算购电支出与放电收入。
- **辅助服务**。分别设置调峰、一次调频和二次调频的资源预留、服务量、结算价、性能系数及考核扣减。
- **容量与其他收入**。按需启用容量补偿、容量租赁及其他经营收入。容量类收入可设置合格或签约容量、年单价、履约系数和有效期。
- **年度收益预览**。切换趋势图和柱状图，查看营业收入、购电及交易费和两者差额。展开年度明细核对放电量、含税与不含税收入及各项支出。

### 融资与税务

配置单笔银行贷款的融资比例、利率、期限和还款方式，支持等额本金与等额本息。建设期只宽限本金，利息由项目资本金支付。按项目公司设置增值税、附加和所得税假设，配置应收应付周转与最低现金储备，并查看初始资金安排、逐年还本付息以及税费和营运资本预览。

### 三情景设置与测算结果

- 为悲观、基准和乐观情景分别设置充放电价格、日循环次数、辅助服务收入、固定运营费用和更新投资系数，在同一项目基础上比较经营假设。
- 全投资按无融资现金流评价，项目资本金计入借款、还本付息及股东投入与回收。结果页汇总 IRR、NPV、回收期等指标，并可切换情景及评价口径查看现金流与风险明细。
- 投决分析图表辅助查看年度收入、购电支出、偿债压力和资本金 NPV 敏感性。模型采用年度假设，适用于项目初筛和内部投决讨论。

### 财务明细与勾稽校验

按情景查看投运期初及逐年利润表、现金流量表、资产负债表、营运资本表、折旧和债务计划表。债务计划列示偿债覆盖率（DSCR）。也可分别查看全投资现金流、项目资本金现金流、日历现金流和分资产折旧。勾稽页展示资产负债平衡、现金滚动、固定资产、债务及增值税等校验的差额和对应期间。

### 演示版说明与多端体验

演示版说明页列出在线开放功能。参数手动录入，计算和保存均在当前浏览器内完成。Excel 参数导入及 Excel、Word 导出暂未开放。网站支持中英文和日间、夜间主题。桌面端使用侧栏导航，iPhone 端提供折叠菜单、可横向滚动的财务表格及 Safari 主屏幕入口。

## 如何使用

1. 打开在线展示站，即可进入工作台并使用示例项目。
2. 调整项目参数和情景假设。
3. 在首页、情景分析和财务明细中查看更新后的结果。

在 iPhone 上，可用 Safari 打开展示站，选择「分享 → 添加到主屏幕」，之后通过储研图标启动。

## 本地运行

项目使用 HTML、CSS 和 JavaScript，无需安装前端依赖或执行构建。如果已安装 Python 3，在仓库根目录运行：

~~~sh
python -m http.server 8000 --bind 127.0.0.1
~~~

然后打开 [本地页面](http://localhost:8000/)。

## 代码入口

| 文件 | 用途 |
| --- | --- |
| `index.html`、`app.js` | 页面入口与应用交互 |
| `evaluation-core.js`、`finance-core.js`、`statements-core.js` | 投资评价、融资和报表计算 |
| `dashboard.js`、`decision-charts.js` | 工作台与分析图表 |
| `localization.js`、`locale-dictionary.js` | 中英文界面 |
| `mobile.css`、`mobile.js`、`manifest.webmanifest` | 移动端布局、导航及主屏幕入口 |
| `demo-mode.js` | 公开展示版的功能配置 |

在线展示由 GitHub Pages 从 `main` 分支根目录发布。

## 展示版范围

计算在浏览器内完成，项目数据保存在当前浏览器。Excel 参数导入及 Excel、Word 导出功能在公开展示版中暂未开放。示例和测算结果用于模型演示和初步分析。
